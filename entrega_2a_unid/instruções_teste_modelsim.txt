# =====================================================================
# GUIA DE EXECUÇÃO E TESTES NO MODELSIM
# Projeto: Processador RISC-V RV32I Customizado (max, sign, mac)
# =====================================================================

1. ABRIU O MODELSIM?
   - Abra o ModelSim e altere o diretório de trabalho (File > Change Directory) 
     para a pasta raiz onde se encontram os arquivos do processador (single_cycle_processor).

2. CRIAR A BIBLIOTECA DE TRABALHO:
   No painel "Transcript" (terminal inferior), digite:
   vlib work
   vmap work work

3. COMPILAR OS ARQUIVOS DO PROCESSADOR E DO TESTBENCH:
   Compile primeiro o pacote de definições e em seguida os demais arquivos:
   vlog risc_v_32_i_pkg.sv
   vlog *.sv

4. INICIAR A SIMULAÇÃO:
   Carregue o módulo principal de teste (top):
   vsim top

5. ADICIONAR OS SINAIS NA JANELA WAVE:
   Para monitorar os registradores, ULA e o fluxo de instruções:
   add wave -position insertpoint sim:/top/PrCore/*

6. EXECUTAR A SIMULAÇÃO:
   Rode o clock por 200 nanossegundos para processar as instruções do programa de teste:
   run 200ns

7. SINAIS PRINCIPAIS PARA OBSERVAR NA JANELA WAVE:
   Pode mudar o formato dos sinais para decimal (botão direito no sinal > Radix > Decimal) para facilitar a leitura.
   - instruction / retire_instruction_o: Código hexadecimal da instrução executada.
   - alu_op_sel: Mostra a operação ativa (OP_ADD, OP_MAX, OP_SIGN, OP_MAC).
   - reg_source_1 e reg_source_2: Operandos de entrada da ULA.
   - reg_source_3: A 3ª porta de leitura, essencial para verificar o acumulador do MAC.
   - retire_rd_value_o (ou reg_data): O valor final gravado no registrador de destino (rd).

# =====================================================================
# 8. DECODIFICAÇÃO DO TESTE (R_type.txt / inst_mem2.hex)
# =====================================================================

O programa de teste executa a seguinte sequência de 10 instruções para validar operações aritméticas, lógicas e as extensões customizadas:

1. 00a00093 -> addi x1, x0, ...   (Configura operando base em x1)
2. 01900113 -> addi x2, x0, ...   (Configura operando base em x2)
3. ff100193 -> addi x3, x0, ...   (Configura operando base em x3)
4. 00300213 -> addi x4, x0, 3     (Configura multiplicando do MAC: x4 = 3)
5. 00400293 -> addi x5, x0, 4     (Configura multiplicando do MAC: x5 = 4)
6. 06400313 -> addi x6, x0, 100   (Configura acumulador inicial do MAC: x6 = 100)
7. 4020e3b3 -> max x7, x1, x2     (Executa a instrução customizada MAX entre x1 e x2)
8. 4000f433 -> sign x8, x1, x0    (Executa a instrução customizada SIGN em x1)
9. 4001f4b3 -> sign x9, x3, x0    (Executa a instrução customizada SIGN em x3)
10. 0052030b -> mac x6, x4, x5     (Instrução customizada MAC: lê a 3ª porta em x6 [100], 
                                  multiplica x4 * x5 [3 * 4 = 12], soma e grava x6 = 112)

# =====================================================================
# 9. INTERPRETAÇÃO DO GABARITO (expected/L_S_type_expected.txt)
# =====================================================================

O gabarito define o estado final esperado para validação automática:
- REGISTER X [hex]: Registrador xX deve conter exatamente o valor hex especificado ao fim da execução.
  Exemplo: "REGISTER 1 ffffffff" -> x1 deve terminar com o valor -1 (0xFFFFFFFF).
- MEMORY X [hex]: Posição de memória de dados X deve conter o valor hex indicado após operações Store.
- COMPLETE X [hex]: Marcador de finalização do testbench confirmando a aprovação do teste.
